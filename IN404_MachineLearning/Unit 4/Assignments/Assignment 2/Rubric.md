# IN404 Unit 4 Assignment 2 Rubric (30 points total)

## Criteria 1: Communicating data using visualizations (18 pts)

Level III (full marks) = all 5 sub-items at 3.6 pts each:

1. Provides a summary of communicating data using visualizations
2. Provides a summary of five reasons to implement data visualizations
3. Summarizes effective and ineffective visualizations; uses examples as needed
4. Describes the visualization methods provided, covers when they should be used, and for what type of data
5. Summarizes two use cases, each, for three selected visualizations that effectively communicate results of machine learning

## Criteria 2: Communication skills (9 pts)

Level III (full marks) = all 3 sub-items at 3 pts each:

1. Writes 3 pages of content
2. Uses highly developed viewpoint, purpose, and exceptional content
3. Provides a well-ordered, logical presentation free of grammatical, punctuation, and spelling errors

## Criteria 3: APA Style and Writing Conventions (3 pts)

Level III (full marks) = all 3 sub-items at 1 pt each:

1. Applies current APA style to in-text citations and references, and document formatting if appropriate, with minor to no errors
2. Writing is focused, concise, and organized and articulates at a college level, with minor to no errors
3. Uses resources from reliable and/or scholarly sources
