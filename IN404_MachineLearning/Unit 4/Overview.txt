In this unit, you will learn about various capabilities to reshape data sets. You will learn about basic indexing, multi-indexing, boolean indexing, and operations on indexes. You will also learn about grouping, merging, and reshaping data. All of which help a data analyst manipulative data sets for the best results. You will apply this knowledge programming a Python solution by manipulating the data for the best accuracy model. Finally, you will learn about communicating data using visualizations.
