Unit 8 Discussion Post — Deep Neural Networks

Initial Post

For this week's discussion, I went beyond the course text and used several sources: the review article "Deep Learning" by LeCun, Bengio, and Hinton (2015), the Stanford CS231n course notes on neural networks, the scikit-learn documentation, and two published studies for my real-world examples. LeCun et al. (2015) describe deep learning as allowing "computational models that are composed of multiple processing layers to learn representations of data with multiple levels of abstraction" (p. 436). That one sentence captures the core idea for me. A deep neural network is a model built from many stacked layers, where each layer learns a slightly more abstract version of the data than the one before it.

The connection to the human brain goes back to the very first model. Rosenblatt's (1958) original paper on the perceptron was titled "The Perceptron: A Probabilistic Model for Information Storage and Organization in the Brain," so the idea started as an attempt to model how the brain learns. The human nervous system has about 86 billion neurons connected by roughly 10^14 to 10^15 synapses (Stanford University, n.d.). A biological neuron receives signals through its dendrites, and if the combined signal is strong enough, it fires a signal down its axon to other neurons. An artificial neuron copies this pattern in a simple mathematical way: it multiplies each input by a weight (similar to the strength of a synapse), adds them up with a bias, and passes the result through an activation function that decides how strongly the neuron "fires." What I found important is that the Stanford notes stress that this model of a biological neuron is "very coarse" (Stanford University, n.d.). So I think of deep neural networks as inspired by the brain, not as a copy of it. Real neurons are far more complex, and the brain does not learn with the same math that neural networks use.

Layering is what makes a network "deep." A network has an input layer that receives the raw data, one or more hidden layers that transform it, and an output layer that produces the prediction. In a fully connected network, every neuron in one layer connects to every neuron in the next (Stanford University, n.d.). Each hidden layer builds on the output of the layer below it. In an image model, for example, the early layers might pick up simple patterns like edges, middle layers combine those edges into shapes, and later layers recognize whole objects. LeCun et al. (2015) explain that the network learns these layers by itself, using the backpropagation algorithm to work out how each internal parameter should change. Backpropagation was popularized by Rumelhart et al. (1986), and it is what made training networks with hidden layers practical.

Building up from the simplest case, a perceptron is a single artificial neuron. It takes weighted inputs, adds a bias, and outputs 1 if the total is above a threshold and 0 otherwise. Training it is simple: when it makes a mistake, the weights are nudged toward the correct answer. In fact, scikit-learn's Perceptron "updates its model only on mistakes" (scikit-learn developers, n.d.-a). A single-layer neural network places several of these neurons side by side, connecting the inputs directly to the outputs with no hidden layers in between (Stanford University, n.d.). The limitation is that a single layer can only draw straight-line (linear) boundaries between classes. A classic example is the XOR problem, where the output is 1 only when exactly one of two inputs is 1. No single straight line can separate those cases, so a single-layer network cannot learn it. A multilayer neural network, often called a multilayer perceptron (MLP), solves this by adding one or more hidden layers between the input and output. Each hidden neuron applies a weighted sum followed by a non-linear activation function, which lets the network learn curved, non-linear boundaries (scikit-learn developers, n.d.-b). The Stanford notes add that a network with at least one hidden layer is a universal approximator, meaning it can approximate any continuous function, and that deeper networks often work better than a single wide hidden layer in practice (Stanford University, n.d.). Our Unit 8 code is a good example of this. It builds a TensorFlow DNNClassifier with three hidden layers of 10, 20, and 10 neurons to classify app reviews as good or bad. I have also built deeper networks before, when I trained a convolutional neural network on the MNIST handwritten digit dataset using both Keras and PyTorch in IN501.

To conclude, I looked at two real-world cases where deep neural networks have been applied successfully. The first is in medical imaging. Gulshan et al. (2016) trained a deep convolutional neural network on 128,175 retinal photographs to detect diabetic retinopathy, an eye disease caused by diabetes that can damage vision if it is not caught early. On a validation set of 9,963 images, the model reached an area under the curve of 0.991, with 90.3% sensitivity and 98.1% specificity at its high-specificity setting. To me, results like these show how a deep neural network could help screen large numbers of patients, especially in places with few eye specialists. The second case is in biology. Jumper et al. (2021) introduced AlphaFold, a deep neural network that predicts a protein's 3D structure from its amino acid sequence, a problem the authors describe as an important open research problem for more than 50 years (Jumper et al., 2021). In the CASP14 competition, AlphaFold's predicted structures had a median backbone accuracy of 0.96 Å, compared with 2.8 Å for the next best method. For scale, the width of a carbon atom is about 1.4 Å, so AlphaFold's predictions were off by less than the width of a single atom (Jumper et al., 2021). Both examples show me that the same layered idea we used to classify app reviews this week can solve problems that matter a great deal for human health.
