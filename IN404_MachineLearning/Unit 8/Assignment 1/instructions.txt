Purpose
In this assignment, you will build a machine learning application that explores advanced machine learning methods to obtain the best results. You will apply models that pipeline count vectorization and TF-IDF with Naïve Bayes, standard scalers, K-Nearest Neighbors (KNN), and a deep neural network using TensorFlow. Finally, you will answer questions showing the results of the code you developed and explore scaling and Z-score further.
