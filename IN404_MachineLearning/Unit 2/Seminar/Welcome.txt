Hello everyone,

Welcome to Unit 2! This week, we move from the foundations of machine learning into how we choose and apply models to real-world problems.

The key idea for this unit is simple: The right model starts with understanding the data.

What You'll Learn

This week, you will explore:
1. Different types of data and when to use supervised vs. unsupervised learning
2. Linear regression for predicting continuous values
3. Logistic regression for classification problems
4. Feature management and challenges with incomplete or streaming data
5. Scalability in machine learning
6. Using NumPy for scientific computing in Python
7. The relationship between AI, Machine Learning, and Deep Learning

 Keep This Question in Mind
