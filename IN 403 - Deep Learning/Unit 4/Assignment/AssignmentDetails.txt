PPE Mask Classification with Transfer Learning + Detection Demo
Course Outcome practiced in this unit:
IN403-3: Use a deep learning model to develop solutions to real life problems

In this assignment, you will build a practical computer vision system using transfer learning in PyTorch. You will train an image classification model to detect whether PPE masks are worn in hospital settings and evaluate its performance using standard metrics. You will also explore the difference between image classification and detection through a short OpenCV demo. The focus of this assignment is not only model performance, but responsible deployment—understanding how errors, privacy, and operational constraints affect real-world use in clinical environments.

Step-by-Step Instructions
1. Open the provided notebook template in Google Colab.
2. Upload IN403_Unit4_PPE_Image_Dataset.zip to the same Colab session.
3. Run the unzip cell to extract the dataset into the ppe_data/ directory.
4. Load the image dataset using ImageFolder and apply the required transforms, including data augmentation and ImageNet normalization.
5. Preview several images and confirm the two class labels: mask_off and mask_on.
6. Load a pretrained ResNet-18 model, freeze the backbone layers, and replace the final classification layer to support two classes.
7. Train the model for five epochs and generate a training loss plot.
    Evaluate the trained model on the test set, report test accuracy, and generate a confusion matrix.
8. Run the OpenCV face detection demo and observe how detection identifies regions in an image rather than recognizing identities.
9. Answer the reflection questions in markdown at the end of the notebook.
